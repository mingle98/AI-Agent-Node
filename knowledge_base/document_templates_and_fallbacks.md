# 文档模板与降级处理知识库（当前实现适配版）

本文用于帮助 Agent 在 Word / PDF / PPT / 通用文件输出场景下，选择**最稳的交付形态**，并在超出边界时优雅降级。

---

## 1. 核心原则

当前项目最适合的文档处理方式不是“高保真编辑原文件”，而是：

1. 读取已有内容
2. 抽取文本或结构
3. 重组成更清晰的输出
4. 生成新的结果文件

也就是说，优先路线是：

**提取 -> 整理 -> 重写 -> 新文件输出**

而不是：

**在复杂原文件里做高保真局部微调**

---

## 2. 输出格式选择规则

### 2.1 什么时候优先输出 `.docx`
适用场景：
- 会议纪要
- 工作总结
- 方案文档
- 操作说明
- 培训材料
- 制度草稿
- 正式文本交付

原因：
- 当前项目对 `.docx` 支持稳定
- 支持标题、段落、列表、基础表格
- 支持 Markdown 转 docx

### 2.2 什么时候优先输出 `.pdf`
适用场景：
- 固化版阅读材料
- 报告导出
- 需要便于发送与归档
- 需要避免用户继续随意编辑

原因：
- 当前项目支持文本/Markdown 生成 PDF
- 支持多个 PDF 合并

提醒：
- 中文显示依赖运行环境字体
- 不应用于承诺复杂原 PDF 版面精修

### 2.3 什么时候优先输出 `.pptx`
适用场景：
- 汇报草稿
- 培训课件提纲
- 数据概览演示
- 客户方案第一页到数页的初稿

原因：
- 当前支持轻量页结构生成
- 支持标题、正文、列表、表格、图片、简单图表、卡片

提醒：
- 更适合“内容骨架”而不是“设计成品”

### 2.4 什么时候优先输出 `.xlsx`
适用场景：
- 汇总表
- 清洗结果表
- 台账
- 统计明细
- 名单筛选结果

### 2.5 什么时候优先输出 `json / csv / markdown`
适用场景：
- 先确认结构
- 中间结果存档
- 用户还没确定最终 Office 交付格式
- 结果需要给其他系统继续处理

## 6. 推荐降级路径

当用户需求超出当前实现边界时，按下面顺序降级：

### 降级 1：从“改原文件”改为“生成新文件”
适用于：
- 原 Word/PDF/PPT 很复杂
- 用户要求局部微调但必须保留复杂原样式

推荐说法：
- 当前更稳的方式是基于原内容生成一份新的结果文件，这样内容准确性更容易保证。

### 降级 2：从“最终 Office 文件”改为“Markdown/JSON 结构稿”
适用于：
- 用户还没确认结构
- 内容量大、规则复杂
- 先想确认框架再导出

推荐说法：
- 我可以先给你一版结构化草稿（Markdown / JSON），确认后再导出成正式文件。

### 降级 3：从旧格式改为现代格式
适用于：
- `.xls`
- `.doc`

推荐说法：
- 当前更适合处理 `.xlsx / .docx`，如果你愿意，建议先转格式再继续，这样稳定性更高。

### 降级 4：从复杂视觉结果改为内容结果
适用于：
- 专业设计 PPT
- 高保真 PDF 编辑
- 保留复杂 Word 版式

推荐说法：
- 当前更适合先完成内容结构和文本结果，视觉级精修建议后续人工调整。

## 7. 推荐问法模板

### 用户说“帮我改成正式文档”
推荐问法：
- 你更希望得到一份新的 `.docx` 正式稿，还是必须在原文档复杂版式上直接改？当前实现更适合前者。

### 用户说“帮我输出一个能发给领导的版本”
推荐问法：
- 你更偏向可编辑的 `.docx`/`.pptx`，还是偏向固定版式的 `.pdf`？如果是阅读与发送优先，通常 PDF 更合适。

### 用户说“帮我做 PPT”
推荐问法：
- 你需要的是汇报草稿型内容结构，还是接近设计成品的视觉稿？当前更适合前者。

### 用户说“尽量保持原文件不变”
推荐问法：
- 你是希望保留原文件并额外生成一个结果文件，还是要求在原复杂版面上高保真修改？默认建议保留原件并生成新文件。

## 8. 文件类型推荐表

| 用户目标 | 推荐输出 | 原因 |
| --- | --- | --- |
| 会议纪要/方案/总结 | `.docx` | 可编辑、结构化支持较好 |
| 正式归档阅读版 | `.pdf` | 固定版式、方便发送 |
| 汇报提纲/简报 | `.pptx` | 适合页结构展示 |
| 数据结果/台账 | `.xlsx` | 适合表格化处理 |
| 中间结果/系统对接 | `json` | 结构稳定 |
| 轻量导表 | `csv` | 兼容性好 |
| 先确认内容结构 | `markdown` | 便于快速审阅 |

---

## 9. 不应误导的说法

不要承诺：
- “我可以完全保留你原文件所有复杂样式不变”
- “我可以直接精修扫描 PDF 内容”
- “我能自动产出设计师级 PPT 成品”
- “老版 `.doc` / `.xls` 可以和新格式一样稳定处理”

---

## 10. 一句话结论

当前项目最稳的文档交付策略是：

**优先把已有内容提炼成结构化文本，再生成新的 `.docx / pdf / pptx / xlsx` 文件；当需求超边界时，优先降级为新文件、结构稿或现代格式。**
